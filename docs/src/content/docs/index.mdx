This site publishes **every sheet** of `Design/Bmw_5441_Design_SysArch_A.xlsx` as
searchable, interactive documentation. Nothing is screenshot-only: tables filter,
functions cross-link, the state machine is clickable, and the original embedded
diagrams are viewable as SVG.
