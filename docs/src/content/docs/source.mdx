## Regenerate

```sh
cd docs
python3 ./scripts/extract_xlsx.py   # needs: pip install openpyxl
npm run build
```

Diagram conversion (workbook `xl/media/*.emf` → `docs/public/diagrams/*.svg|png`)
was done once with Inkscape; re-run only if the drawings change:

```sh
inkscape input.emf --export-type=svg --export-filename=output.svg
inkscape input.emf --export-type=png --export-dpi=200 --export-filename=output.png
```

Inkscape's EMF export omits `viewBox`, which responsive pages need — add it from
the `width/height` in mm (1 mm = 96/25.4 px):

```sh
python3 -c "
import re
MM2PX = 96/25.4
txt = open('output.svg').read()
tag = re.search(r'<svg[^>]*>', txt).group(0)
w = float(re.search(r'width=\"([\d.]+)mm\"', tag).group(1)) * MM2PX
h = float(re.search(r'height=\"([\d.]+)mm\"', tag).group(1)) * MM2PX
open('output.svg','w').write(txt.replace('<svg', f'<svg viewBox=\"0 0 {w:.2f} {h:.2f}\"', 1))
"
```

Fork-agnostic, no workflow committed. Build with:


then publish `docs/dist` with hosting of your choice.
