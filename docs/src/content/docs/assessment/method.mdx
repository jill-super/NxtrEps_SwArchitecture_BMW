## Steps

1. **Identify system key performance parameters** — the 9 KPPs below.
2. **Identify possible system variations** — torque sensor, HW position sensor, probe housing, motor position sensor, motor assembly, hardware (MCU, ECU count, inverter, PWM), coupling position.
3. **Identify affected parameters** — resolution, accuracy, size, redundancy, FIT rate, cost impact, operating conditions, comfort, torque output.
4. **Map affected → KPPs** and 5. **define selection criteria** with weightages (table below; Safety has weight 2, all others 1).
